# Public demonstration boundary

The original `figures4papers` scripts and preview images are intentionally not
included because their upstream repository did not provide a redistribution
license when reviewed. Do not reconstruct or download them automatically.

Use these redistributable alternatives instead:

- `scripts/publication/plot_templates.py` for built-in quantitative examples;
- `scripts/personal/` for explicitly labelled personal simulation examples;
- user-provided figures or code, after reading `asset-adaptation.md` and
  confirming the user has the right to use them.

Learn general composition patterns rather than copying an unpublished or
unlicensed figure. Preserve source attribution and keep data semantics, labels,
and scientific claims tied to the current task.
