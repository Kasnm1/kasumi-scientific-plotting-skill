# 示例参数，不是通用模板要求

打包的IV表属于模拟数据；guangxiangy_optimized.txt是过去人工调整后的光谱，不是原始实测光谱。所有合成输出保留来源标签。

最新IV在3 V、66 μW/cm²：254 nm亮态4.821654 nA、暗态6.680412 pA；324 nm亮态9.449081 nA、暗态6.665890 pA。254 on/off=721.76。这些是示例锚点，不是器件实测结论。

## 脚本对应

- plot_254nm_log_iv.py、plot_324nm_log_iv.py：读取附带IV表，输出对数图。
- plot_wavelength_it.py：旧双波长模拟例，仍为±2%周期波动和800/800 μs，保留原脚本便于追溯。新建同类例时按最新约定将周期波动改成±0.8%，不要误称旧脚本已经更新。
- plot_bias_it.py、plot_frequency_it.py：±0.8%周期净电流变化，800/800 μs无噪声模型，8 pA尾幅、1.8 ms尾常数，暗/亮白噪声RMS 0.5/2 pA。频率例没有额外幅值衰减；这是模型假设。
- plot_rise_fall.py：最终单脉冲示例，rise 811 μs、fall 897 μs（无噪声10–90%交点）；3 ms脉宽，下降尾常数1.89 ms，上升尾常数1.8 ms；尾分量阶跃幅度8 pA。细小波动每40 μs一个节点，节点标准差0.22%、截断±0.5%，叠加0.5 pA暗噪声；截止4.1 ms。
- plot_spectral_current.py：按最新3 V、210 μW/cm²的254/324锚点转换旧调整光谱，模型主峰324 nm、半高宽约42.8 nm；不是新光谱测量。
- plot_polarization_bars.py、plot_polarization_pr32.py：现存偏振模型例，一并备份；其目标比值不作为其他图或实测数据的约束。

注意：改变采样/带宽会改变可观测噪声；这些模型没有仪器噪声谱或带宽校准，不用于证明实测探测率。带噪曲线提取的响应时间未必严格等于无噪声标注。

## 示例运行

在本skill目录执行：

```powershell
python scripts/plot_rise_fall.py
python scripts/plot_bias_it.py
python scripts/plot_frequency_it.py
python scripts/plot_254nm_log_iv.py
python scripts/plot_324nm_log_iv.py
```

示例默认覆盖自己的outputs目录，建议新任务设置独立FIGURE_OUTPUT_ROOT。跨脚本共享的定义通过同目录文件读取，迁移时保持scripts完整。
